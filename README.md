# NEKU Social Casino

MVP responsivo de cassino social criado com React e Vite.

> **Importante:** este projeto usa exclusivamente moedas virtuais sem valor monetário. Não possui depósito, saque, PIX, criptomoedas, compra de fichas, conversão em dinheiro ou premiação real.

## Funcionalidades

- Lobby responsivo para celular e desktop
- Carteira de moedas virtuais
- Bônus diário demonstrativo
- Caça-níquel com multiplicadores virtuais
- Roleta por cores
- Histórico local das rodadas
- Controle de aposta virtual
- Painel administrativo demonstrativo
- Modo de manutenção
- Reinicialização da conta demo
- Aviso 18+ e mensagem de jogo responsável

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

## Próximas etapas recomendadas

1. Autenticação com Firebase ou Supabase.
2. Persistência segura de usuários e saldo virtual.
3. Painel administrativo com permissões por função.
4. Catálogo de jogos, missões e ranking social.
5. Testes automatizados e auditoria da geração aleatória.
6. Política de privacidade, termos de uso e controles parentais.

## Limites do projeto

O código atual é um protótipo de entretenimento local. Para qualquer operação envolvendo dinheiro real, seria necessário interromper o desenvolvimento desta base e realizar análise jurídica, licenciamento, verificação de idade, KYC/AML, geolocalização, auditoria independente e certificação regulatória aplicável.
